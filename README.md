# TVS Order & Delivery Performance Dashboard

An end-to-end SQL and Power BI analytics project developed to analyze
TVS order, customer, dealer, and delivery performance.

## Tech Stack
- MySQL
- SQL
- Power BI
- DAX
- Star Schema

## Dashboard Pages
1. Home
2. Sales Analysis
3. Customer Analysis
4. Dealer Analysis
5. Delivery Analysis
6. Executive Summary
